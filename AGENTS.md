For orientation, read [Adrian’s North Star](../home-repo/NORTH-STAR.md), [Mandala Codes’ product direction](PRODUCT.md#product-direction), and its [current outcome](PRODUCT.md#current-outcome).

Read [the standing orientation TODO](ORIENTATION-TODO.md) at the start of each Mandala Codes task. It records the cross-site acceptance backlog, dated release evidence and registration launch boundaries. Use it as context, not authorization to start unrelated work. When working on an item, update its status and evidence there instead of creating another checklist.

Only for work involving Universal Language or Oracle cards, Oracle writing or research, the Oracle reader/REST/search/MCP runtime, or the i64 OS Oracle/WordForge integration: read `oracle/INDEX.md` before acting. Skip it for unrelated work.

For an Oracle iPhone update, use the fresh-signing build flow in `mobile/README.md`.

for the app and every extension with at least six days, 23 hours remaining.
Report their actual expiration dates; a build number alone does not reset the clock.
