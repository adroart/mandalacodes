## Cross-site contract and limits

Design links are `/creations/<catalogue-id>?from=mandalacodes&card=N`, using explicit
cardNumber metadata (card 1 is UL-122). Art validates the pair and owns the fixed
return to `https://mandalacodes.com/universal-language/N`, including slug redirect.
Physical links use `/works/<artworkId>?instance=<AR-code>` only when canonical public
state supplies the actual code. Never derive a physical code from a catalogue ID.

No art-repository changes, D1 migrations, launch flag changes, real sign-in emails,
payments or metered provider calls were authorized in this repair worktree.
Physical registration/recovery, authenticated deployed handoff, actual provider
success, production schema/bindings and complete restoration need separate proof.
The existing cross-site profile schema and Oracle manuscript remain unchanged.
Publication is held at the coordinator's pending export approval; no push, PR,
merge or deployment has occurred from this branch.

## Reproduce locally

```sh
npm ci
npm run test:unit
npm run typecheck
npm run verify:profile
npm run build
npx playwright test --config=playwright.pwa.config.ts
PLAYWRIGHT_BASE_URL=http://127.0.0.1:2436 npx playwright test --project='Mobile Chrome' --workers=2 --output=/tmp/mandala-mobile-artifacts
```

For a safe read-only acceptance preview after build:
`AUDIT_PORT=2429 node tests/support/audit-preview.mjs`.
It binds loopback, stubs media and APIs, and never forwards provider requests.
Use `x-audit-admin: synthetic` only for the synthetic recorder capability; a real
microphone/provider is neither required nor proved by this server.
