# Panel audits

Each audit covers one of the six card sections. The audit shape is:

1. **What's on screen right now** (read the actual live component)
2. **20 problems**, ordered by severity
3. **Recommendations per problem** — fix, worth doing, or let go
4. **Top 3 fixes** clustered into concrete redesign jobs
5. **Layout sketches** for the chosen fixes (in `../sketches/`)
6. **Locked design intent** — recorded in `../CARD_UI_LOCKED.md`
