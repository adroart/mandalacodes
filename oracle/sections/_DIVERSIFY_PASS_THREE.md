# Diversify pass three, the stem ban

## Why there is a third pass

Pass one banned exact phrases. Agents removed the phrase and kept the stem, so
"The body seats this code IN the chest" became "The body seats this code AT the
chest" and passed every check while changing nothing a reader would notice.

The coordinator's own measurement had the same flaw and reported the field clean
when it was not. That is the lesson: **a ban on a phrase is not a ban on a
sentence.** This brief bans stems.

## Banned stems. A stem is banned no matter what follows it.

**Openings**
- `The body seats this code ...` Any preposition, any continuation. Also banned:
  "This code is seated in", "The body holds this code in", "Seated in the body".
  The whole construction of body-as-subject-seating-the-code is retired.
- `Across the genetic code this ...` Any continuation. Also banned: "In the
  genetic code this", "Across the genetic code, the pairing".

**Closings**
- `What they know together is ...` Any continuation.
- `Read as one ...`, `Held together ...`, `Read together ...`, `Taken together ...`
  The whole family, in every tense and inversion.

## The test to apply to your own sentence

Take your new first five words. Ask: would this sentence work, unchanged, on any
of the other sixty three cards? If yes, it is a formula and you have failed. The
opening must be sayable about THIS card and no other.

That test is the entire point of the pass. Variety of grammar is not enough if
every card still opens by announcing the same abstract relationship.

## What the fields need to keep doing

**BODY > Physiology.** Names where in the body this code lives, and carries real
anatomy. Never drop or soften an organ, gland, system, or mechanism to make a
sentence prettier. Start from the body part itself, from a sensation the reader
knows, or from what the organ actually does. The named anatomy must survive in
the opening or the sentence immediately after.

**RELATIONS > Programming partner (opening).** Names the partner card, by number
and name, and says what the pairing does. The number and name are load bearing
and stay. Several cards lost the number in an earlier pass and had it restored,
so do not lose it again.

**RELATIONS > Programming partner (closing).** Says what the two cards amount to
together. Say it in terms of these two specific cards, not in a formula that
would fit any pair.

## Holds

No em dash, no en dash, no underscore emphasis. No heading changes. No changes to
any card number, card name, hexagram name, arcana name, amino acid, gate, channel,
center, codon ring, or trigram. Field length within ten percent. Edit only, never
rewrite a whole file. Never touch a card outside your list.

## Report

Per card and field: old first five words, new first five words, and for each, one
line confirming the new sentence could not be said about a different card.
