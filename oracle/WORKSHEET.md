# The card worksheet: the framework every card is written through

Adrian, 2026-09-23, after card 63 went out naming its energy by its shadow: "The
frameworking that everything has to be ran through is not optional. And then the
checking after is also not optional but first off the frameworking."

Card 63 had every template and script available and still failed, because the
writer held them in its head instead of on the page. It polished the old
scaffold instead of making the list of true things, ran only the checks a script
can decide, and kept an opening line on file without testing it. Each of those is
a step this file now makes visible, and `npm run card:gate -- NN` refuses a card
whose worksheet is missing or unfinished.

**How to use it.** Copy the block below to `oracle/worksheets/NN.md` before
writing a word of the card. Parts 1 to 3 are the framework and are filled in
first, from the sources, not from the card's existing prose: the existing prose
is what is being replaced, and its framing is the thing most likely to be wrong.
Part 4 is filled in after writing. Every `-` line must carry text; a blank line
fails the gate. Headings exact.

---

### Cold reader

A fresh agent (Sonnet is enough) with no sources, given only the keywords, the
entrance and the CODE section with EVERY SENTENCE NUMBERED (E1, R1 ...),
restates each one in its own words. Unnumbered, it merges and splits sentences
and fails lines it passed a read earlier; numbered, it was steady (card 63).
Re-run it after every fix until one read passes. Paste what it returned,
then one line per sentence it could not restate and what was changed.
