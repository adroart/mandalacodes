# Light Codes artwork integration

The owner chose an artwork-only first release on 2026-11-17. The site now has a numbered 68-work gallery and a view for each artwork. It publishes no archived Summary, Full Description, Meditation Prompt, Affirmation, tags, or reading text. The 64-card Universal Language Oracle and its manuscripts are unchanged.

The bundled `public/images/light-codes/lightcodes-01.png` through `lightcodes-68.png` are byte-for-byte copies of the 68 verified local images recorded in [the source audit](2026-11-17-source-audit.md). Concatenated in numeric order, the bundled files have SHA-256 `239730c93510532b8834f136957e1df8fa46513128475dda8c799ae9e95dd39b`. `data/lightCodes.json` contains only number and category, taken from the 68 source Markdown `## Category` fields. This includes card 9, which was missing from the CSV. The actual category distribution is 14 / 26 / 28; no fallback formula was used.

The existing editorial prerender step now creates initial HTML for `/light-codes` and `/light-codes/1` through `/light-codes/68` from the same React components and data used by the client. The generated Pages route serves known HTML and returns HTTP 404 for unknown numbers and HTTP 503 if a known artifact is absent. Artwork images live outside the Function route under `/images/light-codes/`. The PWA precache list does not include these PNG paths, so browsing this deck does not add a 9.54 MB install download.

Local verification: `npm run typecheck`, the focused `tests/node/light-codes-artwork.test.mjs`, and the full `npm run build` pipeline passed. The build produced 72 editorial HTML pages (the existing 3 plus 69 Light Codes pages), scanned 159 total HTML files for CSP, and retained 9 inline-script hashes. In `wrangler pages dev dist`, the hub and cards 1, 51, and 68 returned HTTP 200 with initial H1/body/canonical/schema, invalid card URLs returned 404, and the copied PNG returned `image/png`. The gallery filter showed 26 results for Embodied Vibration. Direct card 51 navigation to About restored OG image dimensions to 1200 × 630 and removed the card schema. Browser screenshots at 320 × 568, 390 × 850, 768 × 850, and 1280 × 850 had no horizontal overflow; the 320 × 568 card view showed Back, Previous, Next, and the complete card 51 image within the first viewport. The archive's repeated draft phrase was absent from the built assets, and `dist/sw.js` contained no Light Codes PNG precache path.
