# Editorial pages: initial HTML

`npm run build` renders `/about`, `/artists`, and each entry in `data/featuredArtists.ts` from the existing React page components. It writes the body, route metadata, canonical URL, social tags, and JSON-LD into `dist/<route>/index.html` before the postbuild CSP pass. Pages Functions serve these exact assets on both URL forms with and without a trailing slash. The React app then mounts normally and owns navigation and head updates. Unknown artist paths return HTTP 404; a missing asset for a known route returns HTTP 503.

Local verification on 2026-11-17 used the full `npm run build` pipeline and `wrangler pages dev dist`. JavaScript-disabled HTTP/browser checks found an H1, body copy, canonical metadata, JSON-LD, and artwork images in the first response for all three routes. Both URL forms returned 200 with canonical URLs without trailing slashes. Unknown artist paths returned 404; temporarily removing a known artifact returned 503. After JavaScript loaded, navigation from the artist page to the hub and from About to the hub replaced route-specific schema without duplicates and updated the canonical URL. Static mobile and desktop screenshots showed no horizontal overflow. The separate Oracle card prerender and routes were not changed.
